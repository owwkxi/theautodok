Technician Performance Scoring System — Complete Reference

1. Overview

The scoring system tracks technician performance by recording points for every significant event on a Job Order (JO). Points are stored in the technician_points table in real-time. The leaderboard and history are derived directly from these records.

Points are not retroactive. Only JOs processed after the system was deployed will generate points.

5. JO Status Flow & When Points Fire

pending → ongoing → under_inspection → car_washing → completed → released ↘ returned_for_revision ↗ cancelled (from any active status)
JO Status ChangePoints Action
ongoing — timer startedNo points. Timer starts running for technicians.
ongoing → under_inspection (Done button)No points. Timer pauses.
Inspector clicks PassNo points. JO moves to car_washing.
Inspector clicks RevisionAll techs get −5 pts. JO moves back to ongoing.
Any status → completedEach tech gets: Completion + Speed Bonus + Revenue Bonus + Clean Bonus (if eligible). Per-tech duplicate check prevents double-awarding.
completed → releasedNo points.
released → returned_for_revisionAll techs get −10 pts. If clean bonus was already given, add −3 pts reversal.
Technician unchecked (edit JO)−3 pts (if worked) or −1 pt (if never started).

6. Rules

#Rule
1Per-tech, per-JO completion. Each technician earns completion points for a given JO only once. If the JO completes again after a return, the same tech won't get double points — but a new/different tech on the rework will.
2Different tech on rework. If Tech A is removed and Tech B finishes the rework, Tech B earns their own full completion points.
3Penalties stack. Multiple revisions or returns each add their own penalty entry.
4Clean Completion reversed on post-release return. If the tech already earned the +3 Clean bonus and the vehicle returns after release, a −3 reversal entry is added.
5Revenue is based on total_amount. Lead = 1 pt per ₱1,000. Assist = 0.5 pt per ₱1,000.
6Both PUT and PATCH handlers record points. Points fire whether the status is changed from the Edit JO modal (PUT) or the status dropdown (PATCH).
7Date-range filtering. Dashboard and Reports filter points by created_at in the technician_points table.
